# Voice Assistant - Task 1 (Oasis Infobyte)

## Description
A Python-based voice assistant application built using speech recognition and text-to-speech technologies.

## Tech Stack
- Python
- SpeechRecognition
- Pyttsx3
- Webbrowser

## Features
- Responds to greetings ("Hello")
- Tells current date and time
- Opens Google Search for queries
- Plays music on YouTube
- Exits gracefully on voice command

## How to Run
1. Install dependencies: `pip install SpeechRecognition pyttsx3 pyaudio`
2. Run script: `python main.py`
